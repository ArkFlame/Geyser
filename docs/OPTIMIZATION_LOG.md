Rejected (no change): skipping the per-tick empty `sendPacketsImmediately` in GeyserSession.tick. `BedrockPeer.sendPacketsImmediately` with an empty array performs `channel.flush()`, which flushes other queued packets; removing it changes send timing.
No-gain (no change): JavaMapItemDataTranslator / MapColor.fromId. Already a bounds-checked array lookup with a pre-sized int[]; a flat ABGR table would save one dereference per pixel, not worth an unmeasurable edit.
Rejected (no change): BiomeTranslator.multiplyIdToStorage. 4096 checked BitArray.set calls per section; only a word-wise fill per BitArray implementation would help, and that bypasses the set() checks and depends on each implementation word layout. Risk exceeds the expected gain; not measured.
Rejected (no change): remaining eager debug(".." + obj) sites in translator/protocol/java (~25 files). They sit in miss/error branches that are cold in normal play; guarding them saves nothing measurable. Only the two on per-packet default paths (entity event, readSoundEvent) were guarded.
No-gain (no change): InventoryTranslator.makeContainerEntries/makeItemEntry. Already EnumMap + primitive iterator; heap dump 40% is inclusive of the whole request call tree, not self allocation of this method.
Finding (no change): leaf allocation in docs/GEYSER_HEAP_PRESSURE.txt is mostly library code: Cloudburst ZlibCompression/Zlib.deflate (~23% via CompositeByteBuf.nioBuffers/slice), netty ensureWritable/reallocate (~4-6%), NetherNetPacketEncoder.encode (~15%). None is Geyser-owned logic; a Geyser-side change would have to alter wire framing or sibling-library code, out of scope for offline parity tests.
No-gain (no change): LivingEntity.tick lerp (heap dump GeyserSession.tick 12%). Remaining allocations are the immutable position Vector3f and the MoveEntityDeltaPacket, both required output; lerp math already tuned.
No-gain (no change): Geyser-side Bedrock compression. ThresholdCompressionStrategy already skips deflate for batches under 512 bytes; the compression level is user config (wire size), and remaining deflate/nioBuffers cost is inside Cloudburst.
No-gain (no change): item hashing allocation in the heap dump (DataComponentHashers/RegistryHasher <clinit>, lambda linkage) is one-time class initialization, not steady-state per-packet cost.
